# Sentiment Analysis System

## Project Description
A machine learning and Natural Language Processing
application that analyzes text and classifies sentiment
into Positive, Negative and Neutral categories.

## Features
- Single review sentiment prediction
- Bulk CSV review analysis
- Three-class sentiment classification
- Prediction confidence display
- Sentiment distribution visualization
- Downloadable analysis results

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Multinomial Naive Bayes
- Streamlit
- Plotly

## Model Development
The TweetEval Sentiment dataset is used for training
and testing. Logistic Regression and Multinomial
Naive Bayes are compared using evaluation metrics.

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Run the application:

   streamlit run app.py

## Dataset
TweetEval Sentiment dataset from Cardiff NLP,
available on Hugging Face.
